# Gwendi's World
Un monde où Gwendi (vous) peut vivre, malgré les bizarreries de cet univers.

## Cadre

- **Stack** | Vite (NodeJS), Typescript

- **Langue** | Français

- **IA** | Claude (non connecté), pour le conseil et l'apprentissage seulement, pas pour coder l'app

## Développement

Pour coder :
```
cd gwendis-world
```
```
npm run dev
```

Pour déployer sur GitHub Pages :
```
npm run build
```
```
npm run deploy
```

## Prochaines étapes
1. Préparer un mini scénario.
2. Mettre en place une architecture adaptée à ce que peut faire le personnage et l'accomplissement de son but.
3. Importer une police d'écriture.
4. Construire une page d'accueil / d'accroche.
5. Importer un premier son de fond.
6. Créer une interface de création d'histoire.
