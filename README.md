# Gwendi's World
Un monde où Gwendi (vous) peut vivre, malgré les bizarreries de cet univers.

Lien du jeu : **[Gwendi's World](https://anaellejaffre.github.io/Gwendis-world/)**

## Cadre

- **Stack** | Vite (NodeJS), Typescript

- **Langue** | Français

- **IA** | Claude (non connecté), pour le conseil et l'apprentissage seulement, pas pour coder l'app

## Développement

Pour coder :
```
cd gwendis-world
```
```
npm run dev
```

Pour déployer sur GitHub Pages :
```
npm run build
```
```
npm run deploy
```

## Prochaines étapes
1. Préparer un mini scénario.
2. Construire une page d'accueil / d'accroche.
3. Importer un premier son de fond.
4. Créer une interface de création d'histoire.
5. Mettre en place une modification automatique du z-index des éléments du décor, en fonction de leur placement depuis bottom, pour que les objets les plus bas soient toujours devant.
